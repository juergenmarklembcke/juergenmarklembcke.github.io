# Project: Tag-based "Topics" pages for academicpages site

## Final Architecture (Working)

### File Structure

- **`_tags/street-design.md`** and similar — one file per topic, manually created
- **`_tags/template-copy-this.md`** — blank template for creating new topics
- **`_includes/author-profile.html`** — sidebar with tags displayed below email
- **`_data/navigation.yml`** — no "Topics" menu entry (removed)
- **`_config.yml`** — `tags` collection added to `collections:` block

### How It Works

- Tags are added to publication/talk files in Obsidian as `tags: [street-design]` (no `#`)
- One file per topic lives in `_tags/` with permalink `permalink: /tags/tagname/`
- Sidebar collects all unique tags from all publications and talks, then displays them as royal-blue (
    
    Copied
    
    #4169E1
    
    ) clickable links below the email
- Sidebar links go to `/tags/street-design/`
- Topic pages list all matching publications and talks as clickable titles
- No menu entry for "Topics" — sidebar is the only navigation to tags
