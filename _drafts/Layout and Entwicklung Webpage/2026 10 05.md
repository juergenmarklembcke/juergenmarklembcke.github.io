## Project: Academic Pages (GitHub Pages) + Obsidian publication workflow

**Stack:** Jekyll-based `academicpages` theme (Minimal Mistakes fork), synced to GitHub via the Obsidian "Git" Community plugin. Publications are markdown notes in `_publications/`, rendered by Jekyll.

### Goal

Customize how publication metadata renders on the site, and create a reusable blank Obsidian template with fillable Properties fields. Two new custom YAML keys were introduced: **`catalogue_entry`** and **`buy_paper`**.

### Files changed (all committed/pushed)

**1. Obsidian template (blank, copy-to-use)** — stored in the templates folder; fields become editable Properties in Obsidian:

yaml

Copy

```
---
title: ""
collection: publications
category: manuscripts
permalink: /publication/YYYY-MM-DD-slug-here
excerpt: ''
date: 
venue: ''
catalogue_entry: ''
buy_paper: ''
paperurl: ''
citation: ''
---

The contents above will be part of a list of publications, if the user clicks the link for the publication than the contents of section will be rendered as a full page, allowing you to provide more information about the paper for the reader. When publications are displayed as a single page, the contents of the above "citation" field will automatically be included below this section in a smaller font.
```

Note: `collection`, `category`, `permalink` never render on the site. Obsidian sorts Properties alphabetically regardless of file order. URLs are stored as bare strings (no Markdown link syntax). Templater prompts (`tp.system.prompt`) were offered as an optional auto-fill upgrade but the plain static template was chosen.

**2. `assets/css/main.scss`** — original `@import` block kept untouched; appended after it:

scss

Copy

```
/* ===== Custom overrides ===== */
.archive__item-title a { text-decoration: none; }
.archive__item-title a:hover { text-decoration: none; }
.catalogue-entry { font-size: 0.85em; margin-top: -0.4em; }
.buy-paper { font-size: 0.9em; }
```

Purpose: removes the underline from blue/bold publication titles; sizes the two new fields. Must sit _after_ the `@import` list so it wins the cascade. Fallback if specificity fails: `.archive__item-title a, .archive__item h2 a, .page__content h2 a { text-decoration: none !important; }`

**3. `_includes/archive-single.html`** (list view) — approved version uses:

- Venue + date merged into one `<p>`: `Published in <i>{{ post.venue }}</i>, {{ post.date | default: "1900-01-01" | date: "%Y" }}`
- `{% if post.catalogue_entry %}<p class="catalogue-entry">Catalogue entry: <a href="{{ post.catalogue_entry }}">{{ post.catalogue_entry }}</a></p>{% endif %}` directly after that line
- The long `{% if / {% elsif %}` chain over combinations of `post.citation`, `post.paperurl`, `post.slidesurl`, `post.bibtexurl` was **kept as-is**, with `<a href="{{ post.buy_paper }}" class="buy-paper">Buy Paper</a>` appended to each branch
- Single-quote Liquid string comparisons were switched to double quotes (`post.collection == "publications"`, `site.read_more != "enabled"`)

**4. `_layouts/single.html`** (individual publication page) — same venue/date merge and `catalogue_entry` block using `page.` instead of `post.`. The citation/links block was **replaced entirely** with a conditional-render version so nothing appears unless filled:

liquid

Copy

```
{% if page.citation or page.paperurl or page.slidesurl or page.bibtexurl or page.buy_paper %}
  <p style="font-size: smaller">
    {% if page.citation %}Recommended citation: {{ page.citation }}
      {% if page.paperurl or page.slidesurl or page.bibtexurl or page.buy_paper %}<br />{% endif %}{% endif %}
    {% if page.paperurl %}<a href="{{ page.paperurl }}">Download Paper</a>{% if page.slidesurl or page.bibtexurl or page.buy_paper %} | {% endif %}{% endif %}
    {% if page.slidesurl %}<a href="{{ page.slidesurl }}">Download Slides</a>{% if page.bibtexurl or page.buy_paper %} | {% endif %}{% endif %}
    {% if page.bibtexurl %}<a href="{{ page.bibtexurl }}">Download Bibtex</a>{% if page.buy_paper %} | {% endif %}{% endif %}
    {% if page.buy_paper %}<a href="{{ page.buy_paper }}" class="buy-paper">Buy Paper</a>{% endif %}
  </p>
{% endif %}
```

This also fixed a pre-existing bug: the original chain had no `citation and bibtexurl` branch, so that combination fell through and showed nothing.

### Decisions made explicitly

- User is **fine with the older if/elsif chain in `archive-single.html`** — do not refactor it to the cleaner pattern unless asked.
- Requirement: links and their labels must only appear when the corresponding Obsidian field is filled.
- Field order on the website is controlled by the layout files, not the template; Obsidian Properties are alphabetical.
