## Style & Format Decisions

- **Style:** APA 7th edition adapted to German conventions (e.g., `Hrsg.` instead of `Eds.`, German date format `31.07.` or just year, ISBN included for German institutional series).
- **Umlauts/OCR:** Always corrected from OCR artifacts (e.g., `Stadtebau` → `Städtebau`, `fiir/fur` → `für`, `StraBe` → `Straße`, `Grin!` → `Grün!`).
- **Series format:** `(DSSW-Leitfaden; DSSW-Schriften, Bd. XX)` or `(DSSW-Studie; DSSW-Materialien)` etc.
- **Corporate authors:** Used when no individual authors listed (e.g., Herausgeber-only publications).
- **Bearbeiter/Auftragnehmer:** Credited as authors when they are the named contributors (e.g., Planersocietät + scape teams).
- **DSSW editor role:** Dropping Lembcke from author position when he was only internally involved (editorial/redaktion).
- **Publisher:** Full name of DV/DSSW consistently used: `Deutsches Seminar für Städtebau und Wirtschaft im Deutschen Verband für Wohnungswesen, Städtebau und Raumordnung e. V.`
- **Contact/address details:** Always dropped from citations.
- **Catalog links:** Added as `[CATALOG RECORD] https://...` when DNB or isbn.de links were found.

## Publication Types & Formatting Variations

- **Book chapters:** `In ... (Hrsg.), ... (S. xx–xx).` (e.g., Hoppe et al. 1994 in _Mobilität und Kommunikation_).
- **Conference/fair presentations:** `[Vortrag]` with event name and location (e.g., DSSW-Fachtagung, Deutscher Handelsimmobilienkongress).
- **Event-organized talks:** No "in:" — event and host listed in sequence (Option 1).
- **Corporate-author publications:** Used when only Herausgeber listed.
- **Multi-firm projects:** All Bearbeiter from each firm listed (e.g., `Frehn, M., Beilein, A., Tack, A., Funk, M., Scheele, C., & Stark, A.`).
